# Portfolio

Next.js (static export) + Tailwind + shadcn/ui, deployed to GitHub Pages via `.github/workflows/nextjs.yml`.

- Texts live in `src/content.ts`, the page in `src/app/page.tsx`.
- `npm run dev` for local work, `npm run build` writes the site to `out/`.
- Repo name must be `<username>.github.io`; in the repo settings set Pages source to "GitHub Actions".
